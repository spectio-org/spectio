| Id | Severity | Finding | Status |

| CR-P3T11-01 (r1) | major | Two new tests `chown` to another uid with no root guard. CI's `product` job runs as the non-root `runner` user, where `chown(2)` fails with `EPERM`, so both tests would fail on the PR. | fixed in `62bb506`: the two foreign-owner cases are their own tests, skipped unless the effective uid is 0; the symlink, loose and bad-name cases stay unconditional |
| CR-P3T11-02 (r1) | minor | The per-boot caps do not bound refused entries: `used` counts only parsed manifests, so a runs root with many bad run directories is read and logged again at every boot. | CR-P3T11-03 (r1) | minor | A `server.json` that names this node is replaced without checking that the server it records is dead. Two servers on one node with different `db_dir` (`SPECTIO_DB_DIR`, another `$TMPDIR`, the `mkdtemp` fallback) and different ports both start, with two runner loops over one runs root. | **open**, P1 Task 15 (it also changes how the state file is created, SEC-P3T11-02 (r1)) |
| CR-P3T11-04 (r1) | minor | On a SLURM environment, the rebuild writes the local launcher's native ID `<pid>.<start>` into `launches.head_native_id`. Reconciled rows are not visited again, so the tmux launcher inherits IDs in a form it may not use. | **open**, P1 Task 10 (the tmux native ID) |
