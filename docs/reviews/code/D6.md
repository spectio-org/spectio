### CR-1 · minor · The unit tests printed `::error::` lines

- **Where:** `tools/docs/test_check.py`, `run_check`
- **Evidence:** the verbose run showed annotation lines between test names.
- **Problem:** noisy test output, and in CI the lines would show up as real annotations.
- **Proposal:** run the check under `contextlib.redirect_stdout(io.StringIO())`.
- **Found by:** code-reviewer
- **Status:** applied (`0930f5c`).

### CR-2 · minor · No workflow ran the new unit tests

- **Where:** `.github/workflows/docs.yml`, job `docs-gate`
- **Evidence:** the tests existed only for local runs.
- **Problem:** a regression in `check_progress_hook()` could pass CI unnoticed.
- **Proposal:** a step `python3 -m unittest tools/docs/test_check.py` before the docs gate.
- **Found by:** code-reviewer
- **Status:** applied (`0930f5c`). The step uses no new action.

### CR-3 · minor · A full placeholder written anywhere is rendered

- **Where:** `hooks/progress.py` and `check_progress_hook()`
- **Evidence:** the hook replaces the placeholder in raw Markdown, code spans included. A page that quotes the full comment would get a strip or table, and would count as a carrier page.
- **Problem:** this rule was not written down.
- **Proposal:** say it in the docstring and in the spec.
- **Found by:** code-reviewer
- **Status:** applied (`0930f5c`): docstring of `check_progress_hook()`, and [documentation-system.md §3.3](../../specs/documentation-system.md#33-the-docs-gate-run-by-autopilot-after-every-step-and-by-ci-on-every-pr) item 1.

### CR-4 · minor · Two loops over the files

- **Where:** `check_progress_hook()`
- **Evidence:** one loop scans every built HTML page, the other every source page.
- **Problem:** the two passes could be merged.
- **Proposal:** a single pass.
- **Found by:** code-reviewer
- **Status:** kept, acceptable noise. The two loops check different things: any page left with a placeholder, and the pages that must show the output.

### SEC-1 · minor · A local font could be published with the site

- **Where:** `mkdocs.yml`
- **Evidence:** `docs/fonts/*.ttf` is ignored by version control, but MkDocs copies every file under `docs/`, so a local `Virgil.ttf` would go into a locally built and deployed site.
- **Problem:** the font's licence is unconfirmed ([FONT-LICENSE.md](https://github.com/weber8thomas/spectio/blob/0930f5c/tools/diagrams/FONT-LICENSE.md)).
- **Proposal:** `exclude_docs: fonts/*.ttf`, and say in FONT-LICENSE.md that `OFL.txt` covers only the `excalidraw/virgil` release.
- **Found by:** security-reviewer
- **Status:** applied (`0930f5c`). With a dummy `docs/fonts/Virgil.ttf` present, `mkdocs build --strict` passed and the site's `fonts/` held only `OFL.txt`. The dummy was then removed.

### SEC-2 · minor · Annotation injection through the message

- **Where:** `tools/docs/check.py`, `fail()`
- **Evidence:** messages hold tool output, such as the tail of a failed build. A newline in it ends the `::error` command, and the next line can be read as a new workflow command.
- **Problem:** a multi-line message was split, and its later lines could be read as workflow commands.
- **Proposal:** escape `%`, CR and LF as `%25`, `%0D` and `%0A` in the message and in the `file` property.
- **Found by:** security-reviewer
- **Status:** applied (`0930f5c`, `_escape()`), tested by `test_newlines_and_percent_are_escaped_in_the_error_command`, red before the change.
