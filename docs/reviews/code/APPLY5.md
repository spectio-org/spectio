| Id | Severity | Finding | Status |
|---|---|---|---|
| SEC-141 | blocker | the bridge wrote into `<launch dir>/.spectio` without checking it; another user who can write the launch directory could plant a symlink and make the bridge write elsewhere as the user | applied: req. 12 Bridge, launch directory (`O_DIRECTORY\|O_NOFOLLOW`, `fstat`, fd-relative `O_NOFOLLOW` creates, spool 0600, otherwise nothing written); Java `SecureDirectoryStream` and EMBL NFSv4 inherited ACLs **[to be validated]** (inbox #64 note); Task 25 `test_bridge_refuses_foreign_spectio_dir` and its `_snakemake` twin |
| SEC-142 | major | the server read a terminal run's `.spectio/` and engine logs by path; a swap after the check, a symlink or a FIFO could leak or hang | applied: req. 12 Server, reads (one checked descriptor; logs `O_NOFOLLOW\|O_NONBLOCK`, regular file owned by the user, last 64 KiB, else "log not readable"); Task 25 `test_spectio_dir_swapped_after_check_not_read`, `test_terminal_log_symlink_fifo_foreign_refused` |
| SEC-143 | major | two terminal runs in one launch directory shared spool files | applied: spool files `<run ID>-<producer>-<nnnn>.jsonl` (architecture §13.8), only the pointer's run ID read, other envelopes dropped and counted (req. 12); Task 25 `test_two_terminal_runs_same_launch_dir_kept_apart` |
