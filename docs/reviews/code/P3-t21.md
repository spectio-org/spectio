# Code review · P3 Task 21, one wheel with the UI and both bridges

`review-code` on `autopilot/P3-t21`, base `884e5bb`, 2026-11-07. The step is [P1 Task 21](../../plans/P1-walking-skeleton.md#task-21-one-wheel-with-the-ui-and-both-bridges), the last build task of milestone M4 ([P2 §4](../../plans/P2-execution.md#4-m4-api-and-screens)). It adds:

- `packages/spectio/hatch_build.py` and `packages/spectio-server/hatch_build.py`: a hatchling build hook each. The first puts `engine-bridges/nf-spectio/build.sh`'s output (the unpacked plugin) and the Snakemake logger module in the wheel as `spectio/_bridges/`; the second puts `web/dist` in the wheel as `spectio_server/web/`. Each sdist carries those files under `src/`, so a wheel built from it needs neither Node nor Nextflow. An sdist without them fails; a wheel built straight from a checkout goes without them, with a warning;
- both `pyproject.toml` files move from `uv_build` to `hatchling==1.32.4`, with `[tool.hatch.build.targets.sdist] only-include = ["src", "hatch_build.py"]` (SEC-P3T21-01 (r1));
- `spectio --version`;
- `spectio_server/static.py`: `DIST` is the packaged `web/`, else the workspace checkout's `web/dist`, used only from an owned, unwritable root (`find_dist`, SEC-P3T21-02 (r2));
- `tests/packaging/test_wheel.sh` with the wheel lists in `tests/packaging/contents/`: builds with `uv build --all-packages`, compares the files of each wheel and each sdist with the lists, installs `spectio` alone, and checks the version, the packaged bridges, the 80 MB limit and the packaged screens.

The reviewers were `code-reviewer` and `security-reviewer`, independent and in parallel. Format: [`README.md`](../README.md). The wheel layout is owned by [architecture §7.3](../../specs/architecture-plugins-and-packaging.md#73-python-bundle) (Python bundle, 0.0.1 prerequisites) and §6; the screens' serving rule by [dev-env §15.3](../../specs/dev-environment-and-testing.md#153-001-on-a-cluster-architecture-and-safety-without-accounts) req. 17.
