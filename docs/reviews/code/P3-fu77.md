# Code review · FU-P3-77: write head.exit without a child a cancel can kill

`review-code` on `autopilot/P3-fu77`, base `b3e11a89`, head `c5ed5a5b` (one commit), 2026-11-08. The step is FU-P3-77: on PR #172 the tmux launcher test `test_argv_never_single_string` timed out twice. A Cancel sends SIGTERM to the head's whole process group; the head traps it, but the `date` of `$(date +%s)` in the head's tail does not, so `head.exit` was left as `130 \n`. `read_head_exit` refuses it, the head reads `unknown`, and the run never ends. The behaviour is owned by [schedulers §3.1.1](../../specs/schedulers-and-monitoring.md#311-local-launcher-detach-adopt-exit) (PID and exit files, note 2026-11-08). Progress: [P3 · M5, FU-P3-77](../../progress/W5/P3-M5.md#fu-p3-77-a-cancels-sigterm-no-longer-spoils-headexit). Format: [`README.md`](../README.md).

Outside `docs/`: 5 files, +43 −2 over the base; none added or removed under `packages/*/src` (`git diff --stat b3e11a89..HEAD -- packages`).

## What the step does

- **`headscript.py`:** the tail writes `printf '%s %(%s)T\n' "$code" -1 > .spectio/head.exit.tmp`. The epoch comes from bash's own `%(fmt)T`, so there is no child process to kill. A comment cites FU-P3-77. One line changed, 3 comment lines added.
- **Fixture `term_in_tail`** (`conftest.py`): a `date` on the head's PATH that runs `kill -TERM 0`, then execs the real `date`.
- **`test_term_while_head_exit_is_written`,** in `test_local_launcher.py` (engine exits 3) and `test_tmux_launcher.py` (engine exits 4): wait for `head.exit`, check `read_head_exit` gives the code, check `ended()` reports it.
- **Requirement:** bash 4.2 or later (`%(fmt)T`: [bash NEWS](https://tiswww.case.edu/php/chet/bash/NEWS), bash-4.2 item m; `-1` is the current time: [Bash manual](https://www.gnu.org/software/bash/manual/html_node/Bash-Builtins.html)). The bash on the EMBL login node is **[to be validated]**: the [audit](../../research/2026-11-08-embl-login-node-audit.md) names Rocky Linux 8.10 only.
