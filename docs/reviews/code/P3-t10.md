# Code review · P3 Task 10, tmux launcher on the login node

`review-code` on `autopilot/P3-t10`, base `263cd00`, 2026-11-07. The step is [P1 Task 10](../../plans/P1-walking-skeleton.md#task-10-tmux-launcher-on-the-login-node), the last task of milestone M2 ([P2 §2](../../plans/P2-execution.md#2-m2-heads)). It adds:

- `packages/spectio/src/spectio/runner/tmux.py`: `TmuxLauncher`. Each head is the command of a detached session `spectio-<run_id>` (`new-session -d -P -F '#{pane_id} #{pane_pid}'`, separate arguments, `-c <launch dir>`, no `setsid`). The native ID is the session name. Adopt matches the session's pane to `head.pid`; cancel sends Ctrl-C to the pane, then SIGTERM and SIGKILL to the head's group after the grace period, with the PID check before each signal;
- `runner/local.py`: `read_head_exit`, split out for both launchers;
- `packages/spectio-server/src/spectio_server/serve.py`: the runner loop now starts on a SLURM environment, with `TmuxLauncher`; the start text names `tmux attach`; `Booted.loop` is never `None`;
- `web/src/runs/RunDetailPage.tsx`: "Open the head by hand" targets the exact session, quotes each value, and shows no commands for a node or session outside a plain name (SEC-P3PARA-01);
- tests: `tests/test_tmux_launcher.py` (a fake `tmux` in `tests/fakebin/tmux`), `tests/test_tmux_real.py` (a real tmux, marker `tmux`, skipped where tmux is absent), and `test_serve.py`, `RunDetailPage.test.tsx`.

The reviewers were `code-reviewer` and `security-reviewer`, independent and in parallel. Format: [`README.md`](../README.md). The launcher is owned by [schedulers §3.1.1](../../specs/schedulers-and-monitoring.md#311-local-launcher-detach-adopt-exit) (tmux launcher); the signal and tmux rules by [dev-env §15.3](../../specs/dev-environment-and-testing.md#153-001-on-a-cluster-architecture-and-safety-without-accounts) req. 11.
