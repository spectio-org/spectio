## What the step does

- **`DetailSheet.tsx` (`ProcessTasks`):** each task row is a two-column grid, **Task** (Snakemake: **Job**) then **State**, with an `aria-hidden` header row above; the tag chip is gone, since the label ("ALIGN (S01)") already carries the tag. The row's accessible name now ends with its state ("Open task ALIGN (S01), Running"). The first page is read again on each frame while the run is active (`useFrames`), and the rows Load more added are kept.
- **`stateWord.ts`:** `Shown` and `refresh` move here from `RunDetailPage.tsx` so that the Tasks tab and the sheet share them.
- **`RunDetailPage.tsx` (`LogTail`):** the Summary's log tail is read again on each frame of an active run.
- **`runs.css`:** `.sp-task-head` and `.sp-task-rows .sp-sheet-row` share one grid, `minmax(0, 1fr) 9.5rem`. The 9.5rem width is assumed.
- **Tests:** in `DetailSheet.test.tsx`, the paging test now checks the header and the two columns, a new test for the frame re-read that keeps Load more's rows (none once the run has ended), and the CR-P3FU80-02 test; in `RunDetailPage.test.tsx`, the log tail is read again on a frame and not after the run ended.
