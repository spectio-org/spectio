# Code review · P3 Task 5, the Snakemake mapping

`review-code` on `autopilot/P3-t05`, base `85bc086`, 2026-10-30. The step is [P1 Task 5](../../plans/P1-walking-skeleton.md#task-5-snakemake-mapping). It adds:

- `spectio_server.projector.snakemake`: the Snakemake branch of `ingest`, and `head_exit`, which ends a Snakemake launch on its head's exit code;
- in `spectio_server.projector.runs`: the engine's time on run start and end (`Projection.event_time`, `set_started`), and `task_id` and `pin_engine_version`, moved out of `nextflow.py` to be shared;
