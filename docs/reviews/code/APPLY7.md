## Security review (SEC-150 to SEC-159)

The controls are in dev-env §15.3 req. 13 to 16; the tests are in P1 Tasks 28 to 31.

| Id | Severity | Finding | Status |
|---|---|---|---|
| SEC-150 | security | resolving a path then opening it left a swap window | applied: the walk in checking-scenarios §11.1 (revised 2026-10-28): `openat` from the root with `O_DIRECTORY` and `O_NOFOLLOW` per component, `fstat` on the leaf, `readlinkat` followed only into the same run's work directory, `fstatat` for listings; req. 13; `test_req13_dir_swapped_mid_request`, `test_req13_symlink_to_home_refused`, `test_req13_published_symlink_served`, `test_req13_symlink_fifo_refused` |
| SEC-151 | security | a report in a tab of its own could be framed or framed away | applied: req. 14: the report viewer page with an `<iframe sandbox="allow-scripts allow-downloads">`, raw HTML served with the CSP `sandbox allow-scripts allow-downloads` and `frame-ancestors 'self'`; `test_req14_headers`; boards `LiteReportViewer`, `LiteResults` |
| SEC-152 | security | Snakemake Resume could unlock a directory whose head still runs | applied: req. 16 and api §5.1: a head Spectio cannot check counts as alive; `--unlock` only when the head is proven gone; one child per launch directory with `.spectio-launch.lock` and `BEGIN IMMEDIATE`; `test_req16_parent_head_unverified_409`, `test_req16_no_unlock_when_live`, `test_req16_one_child_parallel` |
| SEC-153 | security | `sacct` load on the shared accounting database | applied: req. 15: one limiter (one call in flight, 60 s apart, 100 IDs a call), no bulk queries on rebuild or replay, a cache in `.spectio/sacct.json`; `test_req15_limiter`, `test_req15_rebuild_no_calls`, `test_req15_cache_file` |
| SEC-154 | security | the launch directory could change between the check and the child's start | applied: req. 16: dev and inode checked again before the child starts, `umask 022`; `test_req16_dir_swapped`, `test_req16_planted_config` |
| SEC-155 | security | hiding values in `.command.run` with a regex | applied: req. 13: a shell lexer that fails closed, container environment flags included, and `unset NXF_DEBUG` in the head script; `test_req13_redact_lexer`, `test_req13_redact_container_env`, `test_req13_redact_fails_closed`, `test_req13_command_run_redacted` |
