# Code review · P3 Task 17, inspect a pipeline and launch a run

`review-code` on `autopilot/P3-t17`, base `643dd89`, 2026-10-30. The step is [P1 Task 17](../../plans/P1-walking-skeleton.md#task-17-launch-api), built in the local-only order of [inbox #80](../inbox.md#80-assumed-a-visible-slice-earlier-in-the-p1-order) (a), before Tasks 12 to 16. It adds:

- `packages/spectio-server/src/spectio_server/api/workflows.py`: `GET /api/v1/workflows:inspect`, the location and Git rules, the fetch, and the no-follow reads of a pipeline's files;
- `api/runs_write.py`: `POST /api/v1/runs`, the body checks, the parameter check against the pipeline's schema, the run directory, then the rows and the `launch` command in one transaction;
- `api/browser.py`: the Host allow-list, cross-site and write checks before every route (dev-env §15.3 req. 4 and 7);
- `api/problems.py`: `422 validation-failed` with `errors: [{field, message}]`;
- `store/runs.py`: `insert_run` and `first`, shared by `POST /runs` and the index rebuild;
- `app.py`: the routers, mounted only in local mode on a machine that does not look shared (`shared_host`, `no_api_reason`); `serve.py`: the start text takes that one decision; `sink.py`: a launch stays active until its head is reported ended; `rebuild.py`: the Git import rule;
- tests: `tests/api/test_launch.py`, `tests/api/test_req4_req7_browser.py`, `tests/security/test_shared_host.py`, `tests/test_serve.py`, and four schema fixtures under `tests/data/`;
- dependencies `jsonschema>=4.23,<5` and `pyyaml>=6.0.2,<7`; dev dependencies `httpx>=0.27`, `types-jsonschema`, `types-pyyaml`.

The reviewers were `code-reviewer` and `security-reviewer`, independent and in parallel. Format: [`README.md`](../README.md). The endpoints are owned by [api §5](../../specs/api-and-data-model.md#5-endpoint-catalogue-api-v1) (note 2026-10-30) and [Imports are untrusted input](../../specs/api-and-data-model.md#imports-are-untrusted-input); the browser checks by [dev-env §15.3](../../specs/dev-environment-and-testing.md#153-001-on-a-cluster-architecture-and-safety-without-accounts) req. 4 and 7; the rules the code assumed by [inbox #86](../inbox.md#86-assumed-the-001-launch-api-served-in-local-mode-only-before-sign-in).
