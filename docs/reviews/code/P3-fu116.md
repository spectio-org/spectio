## Assumptions the task made

- The square icons come from AG Grid's empty `span.ag-icon` when an icon is not given (`withoutPart('iconSet')`); the fix gives inline SVG for six icons. CSP and `data:` URIs are unchanged.
- `ag-icon-aasc` and `ag-icon-adesc` are AG Grid 36's absolute-value sort icons, always hidden; they did not cause the squares.
- Search by run ID suffix looks only at the 200 newest runs, because `GET /runs?q=` matches a name prefix and the API has no ID-suffix match before `GET /search`. Older runs need a server-side fix.
- Pin focus finds the button by its row-id in the DOM, because `getRowNode` needs the RowApi module, which is not registered.
- CR-P3FU101A-04 was already fixed in P3-B13; nothing to do.
