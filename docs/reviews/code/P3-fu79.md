## What the step does

- **Favicon.** `web/index.html` links `/src/assets/favicon.svg`, a copy of `docs/assets/brand/favicon.svg` (the emblem alone; `cmp` says the two files are identical). The worker reports that Vite emits it under `/assets`, which the server already serves with `img-src 'self'`.
- **`useLiveStatus()`** (`web/src/live.tsx`, 7 lines): opens the live stream if no screen has, and returns its status, so the shell follows the stream on every page.
- **`AppShell`** (`web/src/shell/AppShell.tsx`):
    - while the stream is `reconnecting`, the sidebar foot and the top bar read "Server not reached" (the `down` text is "The live stream is reconnecting.");
    - each reconnection reads `GET /version` again, as the server may have changed;
    - a successful read clears `down`; a failed one hides the last known server (`reached` is `null`), while `ServerContext` keeps it.
- **Tests,** `web/src/shell/status.test.tsx`, 5 tests: reconnect then re-read (sidebar), a failed re-read after a reconnection (CR-P3FU79-01), a failed first read then the stream opens (CR-P3FU79-02), the phone node pill, and the `index.html` link plus the emblem file.
