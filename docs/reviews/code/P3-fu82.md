With no links, and for Nextflow, the order is the first-seen order. Links that are not names, name an unknown rule, or link a rule to itself are ignored. A cycle leaves its rules last, in list order; no rule is dropped. The order of `items` is unchanged. `models.Process` gains `pipeline_order: int`; the OpenAPI snapshot is regenerated.

Without `pipeline_order`, the view keeps the API's order (stable sort). `api.ts` adds an optional `pipeline_order`; `runs.css` adds `.sp-order`.
