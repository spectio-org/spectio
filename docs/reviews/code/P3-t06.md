# Code review · P3 Task 6, `nf-spectio` writes the spool

`review-code` on `autopilot/P3-t06`, base `a758cf3`, 2026-10-30. The step is [P1 Task 6](../../plans/P1-walking-skeleton.md#task-6-nf-spectio-writes-the-spool). It adds:

- `engine-bridges/nf-spectio/src/spectio/SpectioPlugin.groovy`: a `TraceObserverV2` plugin, ported from the spike T2 prototype. The hooks enqueue allow-listed data; one writer thread appends envelopes to the spool and rotates;
