Cause: a head under tmux writes only `head.out`, so a failed run asked for `/logs?source=head-err` and got 404 (inbox #155, finding 1). `GET /runs/{id}` now returns `head_logs`, the head logs that can be read (`files/taskfiles.py:head_logs`, the same confined read as the log route). The UI shows the Head errors card and source only when `head-err` is listed. ## Assumptions

- If the launch directory cannot be read in time (gone, unreachable, timeout), `head_logs` is `[]`, and a failed run shows the engine-log card instead of the head-errors card.
- A FIFO or a symlink named `head.err` does not count as a head log.
- A linked `?source=head-err` with no `head.err` falls back to the engine log.
