## Findings and open questions

**What the round says.** The niche is still open, but it is narrower than the specs say. FlowO and panoptes (MIT) already monitor Snakemake, and FlowO has a catalogue with MCP access. Flyte 2 started running Nextflow pipelines with pause-until-signal this month. **The findings that matter most** (as ranked in the [review file's summary](../../reviews/R9-landscape.md#summary)):

1. [FC-039 · major](../../reviews/R9-landscape.md#fc-039-major-the-snakemake-adapter-must-add-spectio-to-the-users-loggers-not-replace-them): a plain `--logger spectio` would replace the user's own Snakemake loggers (panoptes, snkmt, FlowO). `--logger` takes a list (`cli.py:1623-1628`), and the API path only uses the handlers Spectio passes (`logging.py:648`). The adapter must add `spectio` to the effective loggers.
2. [FC-038 · major](../../reviews/R9-landscape.md#fc-038-major-a-snakemake-ro-crate-exporter-exists-the-synthesis-says-none-was-found): a Snakemake RO-Crate exporter exists. `snakemake-report-plugin-rocrate` (`1989c5b`, MIT, 0.1.0) writes a WRROC 0.5 Provenance Run Crate. It is not on PyPI yet, so it is a dependency to watch, not to rely on.
3. [FC-041 · major](../../reviews/R9-landscape.md#fc-041-major-ro-crate-and-wrroc-versions-are-not-pinned-and-wrroc-06-breaks-compatibility): api §10 pins no RO-Crate or WRROC version. nf-prov declares WRROC 0.1, Sapporo and the Snakemake plugin 0.5, all on RO-Crate 1.1. WRROC 0.6 needs RO-Crate 1.3 and is not backward compatible. Proposal: pin RO-Crate 1.1 + WRROC 0.5 for 0.x and validate exports in CI.
4. [FC-043](../../reviews/R9-landscape.md#fc-043-major-flyte-2-now-runs-nf-core-pipelines-with-pause-until-signal-the-niche-is-open-verdict-needs-a-precise-boundary) and [FC-042 · majors](../../reviews/R9-landscape.md#fc-042-major-the-snakemake-monitoring-landscape-has-moved-logger-plugins-an-active-panoptes-and-flowo): "no project found targets exactly this" and "no incumbent" for Snakemake are now false. The adoption note cites a 2021 docs build. The verdict holds only when restated as four differentiators: shared POSIX file systems, the user's own account, Snakemake, item-level QC gates.
5. [FC-040 · major](../../reviews/R9-landscape.md#fc-040-major-spectio-cannot-pin-snakemake-a-supported-version-range-and-a-contract-test-are-needed): `DefaultFilter` changed signature three times within Snakemake 9.x, and the logger interface added `needs_rulegraph` in 2.1.0, yet dev-env tests only 9.27.1. Proposal: a stated supported range, two tested versions and the interface's own tests. It conflicts with [R4 CH-009](../../reviews/R4-constraints.md#ch-009-major-snakemake-the-logger-interface-keeps-moving-only-snakemake-9-works-and-snakemakeapi-cannot-run-from-the-runners-environment) on supporting one interface major or two.
