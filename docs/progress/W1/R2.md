## Findings and open questions

**Top findings** (all major, all in [R2-open-validations.md](../../reviews/R2-open-validations.md#majors)):

- **[FC-001](../../reviews/R2-open-validations.md#fc-001-major-snakemake-drains-on-sigterm-sigint-and-a-plain-scancel-lose-running-work): the wrong stop signal.**
    - Snakemake already stops gracefully on SIGTERM.
    - SIGINT cancels running cluster jobs.
    - A plain `scancel` kills the head job with SIGKILL after `KillWait` (30 s by default), so a Nextflow head can die before it cancels its task jobs.
    - The pause, stage-stop and cancel designs in synthesis, schedulers-and-monitoring and checking-scenarios use the wrong signal.
- **[FC-006](../../reviews/R2-open-validations.md#fc-006-major-squeue-name-does-not-take-wildcards-so-runner-restart-reconciliation-finds-no-head-jobs) and [FC-007](../../reviews/R2-open-validations.md#fc-007-major-the-snakemake-job-name-lookup-cannot-work-as-written-and-it-collides-with-the-head-job-names): `--name` lookups find nothing.**
    - `squeue --name` and `sacct --name` match exact names only (`src/squeue/print.c:3263-3275`).
    - Reconciliation after a runner restart uses `--name 'spectio-*'`, so it finds nothing, and "no run is lost" fails.
    - Snakemake names its task jobs `<prefix>_<uuid>`, so the lookup misses them too.
    - R1 SR-037 reports the same problem. R2 adds the source evidence.
- **[FC-002](../../reviews/R2-open-validations.md#fc-002-major-the-generated-extwhen-overrides-a-pipelines-own-extwhen-nf-corernaseq-3270-already-sets-one): the generated `ext.when` replaces the pipeline's own.** nf-core/rnaseq 3.27.0 sets `ext.when = { !params.use_rustqc }` on MARKDUPLICATES. A live check would change what the pipeline does, so the generated value must wrap the original.
- **[FC-003](../../reviews/R2-open-validations.md#fc-003-major-depictio-cli-ingest-user-needs-depictios-instance-provisioning-key-not-a-short-lived-credential): depictio ingest needs the provisioning key.** `depictio-cli ingest --user` requires depictio's instance-wide provisioning key (`run.py:1637-1643`). As written, the runner on the cluster would need that long-lived secret, which breaks the scoped-token rule.
- **[FC-005](../../reviews/R2-open-validations.md#fc-005-major-snakemakes-kubernetes-executor-requires-remote-storage-the-rwx-option-does-not-apply-to-it): Snakemake on Kubernetes needs S3.** The executor sets `implies_no_shared_fs=True`, so remote storage (for example S3), with `--default-storage-provider` and `--default-storage-prefix`, is mandatory. The chart's "RWX or S3" choice applies only to Nextflow.
- **The other majors:**
    - [FC-004](../../reviews/R2-open-validations.md#fc-004-major-uv-tool-install-does-not-guarantee-a-uv-managed-python-so-the-sqlite-floor-is-not-guaranteed-either): `uv tool install` may use a system Python, so the SQLite floor is not guaranteed. The fix is `--managed-python`.
    - [FC-008](../../reviews/R2-open-validations.md#fc-008-major-a-pre-install-migrate-hook-runs-before-the-charts-configmap-and-secrets-exist): a Helm pre-install migrate hook runs before its ConfigMap and Secrets exist.
    - [FC-009](../../reviews/R2-open-validations.md#fc-009-major-snakemake-executor-plugin-kueue-is-an-unmaintained-010-prototype): `snakemake-executor-plugin-kueue` is a 0.1.0 prototype from 2024.
