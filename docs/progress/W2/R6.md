## Why

Before code starts, the API must be able to serve the 0.0.1 screens. R6 tests that in two moves. First, write the 0.0.1 contract as OpenAPI from [`api-and-data-model.md`](../../specs/api-and-data-model.md). Every place where the specs are silent or disagree gets an `x-spec-gap` key. Then two reviewers read the draft from both sides: the spec-reviewer against the specs, the ux-reviewer against every number, list and action on the boards of [`mvp-0.0.1.md`](../../specs/mvp-0.0.1.md) §2.

**Main themes,** as the review file's summary groups them:

1. **No ingest contract.** The draft had to invent the batch envelope, the acknowledgement, the heartbeat and the engine event names ([SR-080](../../reviews/R6-contract.md#sr-080-major-ingest-14-the-wire-items-the-draft-had-to-invent-beyond-sr-054s-subset)).
2. **No contract for the run's inner structure.** No stages resource, no stage or task state enum, and the Legend board does not match the draft's enums ([SR-082](../../reviews/R6-contract.md#sr-082-major-stages-have-no-api-contract-no-resource-no-state-enum-no-single-identifier), [SR-083](../../reviews/R6-contract.md#sr-083-major-task-and-attempt-states-no-owner-no-stored-enum-display-labels-used-as-values), [UX-290](../../reviews/R6-contract.md#ux-290-minor-legend-and-the-draft-enums-disagree-no-cancelling-or-pausing-chip-stored-vs-cached-storedir-stage-states-free-text)).
3. **Run actions and relaunch are under-specified.** Source states, a fourth spelling of the relaunch modes, lineage, resource overrides and the preview ([SR-081](../../reviews/R6-contract.md#sr-081-major-run-actions-and-relaunch-source-states-responses-the-dialogs-three-meanings-of-resume-lineage-and-a-fourth-mode-vocabulary), UX-280 to UX-282, UX-289).
4. **The 0.0.1 gate cannot be served end to end.** No `run` filter, check values without thresholds, no read of a decided gate, and the gate board's main button needs a change set ([SR-085](../../reviews/R6-contract.md#sr-085-major-the-001-gate-no-run-filter-untyped-check-values-without-thresholds-unclear-if-match-no-response-body-label-only-actor-kinds-verbs-still-split), UX-283 to UX-285).
5. **The `Run` resource lacks the fields the boards show.** Workflow name, progress, task totals and timestamps cost 3 to 5 calls per list row ([UX-271](../../reviews/R6-contract.md#ux-271-major-list-rows-need-a-run-progress-and-context-summary-today-that-is-35-calls-per-row), UX-270, UX-272, UX-273, UX-288, SR-088).
6. **Wire conventions, events and SSE frames are not stated** ([SR-090](../../reviews/R6-contract.md#sr-090-major-conventions-list-member-default-limit-sortable-fields-idempotency-key-rules-id-prefixes-field-errors-and-the-problem-type-catalogue), [SR-084](../../reviews/R6-contract.md#sr-084-major-events-and-sse-frames-outside-the-complete-catalogue-no-sequence-for-sse-only-frames-no-data-schemas)).
