# F5 · Documentation system, figures and media tooling

!!! success "Done 2026-10-26 · spec v0.1, landing page, docs gate, 4 doc agents"

## What changed

- **Spec:** the [documentation system](../../specs/documentation-system.md). Docs are part of the definition of done. depictio's site format is kept, its gaps are closed, writers and reviewers are separate agents, PR bodies carry the docs, and PRs auto-merge.
- **Site:**
  - a new [landing page](../../index.md) (hero video, ecosystem and component cards, numbered ideas, the gate figure, a cast, the progress strip);
  - theme colours from the design tokens;
  - this Progress tab, generated by `hooks/progress.py`;
  - an empty [changelog](../../changelog/index.md) with the block template.
- **Tools:**
  - `tools/diagrams/sketch.py`, ported from depictio (MIT) with Spectio glyphs;
  - two figures;
  - `tools/media/`: generated casts, a screenshot registry, combined terminal and browser captures, a churn guard;
  - `tools/docs/check.py`, the docs gate.
- **Agents and skill:**
  - agents `doc-writer`, `doc-reviewer`, `diagram-artist`, `media-capture`;
  - skill `write-docs`.
- **Repository:** the PR template, and `docs.yml` with the required checks `docs-gate` and `pr-body`.

## Why

Thomas: the most important part of the loop is that each step is written up and verified, incrementally, in MkDocs. He wants depictio's format, real diagrams rather than boxes, screenshots, videos and casts, and agents that write next to agents that review.
