## Findings and open questions

- **`nextflow run nf-core/x -r v` failed through the session proxy.** Nextflow reads the manifest through the GitHub API, which answered "Forbidden". Cloning with git avoids it.
- **Limits must stay below the free memory.** With limits at 7 GB on an 8 GB machine, the local executor refused a 6 GB task ("avail: 5.8 GB").
- **The private-runner limit had the same problem.** `corpus.yaml` set 7 GB for 8 GB runners. It is now 6 GB, and the T7 prompt asks to measure the memory GitHub runners really leave free **[to be validated]**.
- **Not proven at F3; later:** the workflows have since run on GitHub runners (`d1852e7`, "ci: fix the docs gate on GitHub runners; park release-please until an App token exists"; `f72e1e1`, "docs(dev-env): record the first live preview deploys"). Step T7 makes the pipeline workflows green.
