## Findings and open questions

- **`nextflow run nf-core/x -r v` failed through the session proxy.** Nextflow reads the manifest through the GitHub API, which answered "Forbidden". Cloning with git avoids it.
- **Limits must stay below the free memory.** With limits at 7 GB on an 8 GB machine, the local executor refused a 6 GB task ("avail: 5.8 GB").
- **Not proven yet:** the CI workflows have not run on GitHub; the session has no push access. Step T7 makes them green.
