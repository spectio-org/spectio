# D6 · Docs pipeline in CI (minimal version)

!!! info "Built 2026-10-27 on `autopilot/D6` · minimal version, on Thomas's request (tight budget) · the build check now covers the `hooks/progress.py` output · Virgil: OFL-1.1 confirmed for `excalidraw/virgil`, the local copy stays uncommitted · mike, Zensical, `shared_images.py`, CI PNG rendering and the F4 and F6 figures deferred"

## What changed

This is the **minimal version** of D6. It does three of the prompt's items. The rest is listed under [Deferred](#deferred-to-a-follow-up-step).

- **`tools/docs/check.py`:** the `build` check now checks the built site for the output of `hooks/progress.py`, in a new function `check_progress_hook()`:
    - it fails when any built HTML page still holds a `spectio:progress-strip` or `spectio:progress-table` placeholder comment;
    - it fails when a page whose source carries a placeholder was not built, or has no rendered strip (`class="sp-waves"`) or table (a `Kind` column header);
    - the pages with placeholders are found from the sources, not listed by hand: today `index.md` and `roadmap/index.md` (strip) and `progress/index.md` (table).
- **`tools/docs/test_check.py`, new:** 6 unit tests for that check, on a temporary docs folder and site. They were written first and failed before the check existed.
- **`docs/fonts/OFL.txt`, new:** the copyright line of `excalidraw/virgil`'s `LICENSE.md` and the SIL Open Font License 1.1 text. The font itself is still not committed ([inbox #1](../../reviews/inbox.md#1-virgil-font-licence-blocks-publishing-the-hand-drawn-figures-font)).
- **`tools/diagrams/FONT-LICENSE.md`:** rewritten with the dated sources. The `excalidraw/virgil` release is OFL-1.1. The depictio copy used locally carries another copyright (`Virgil GS`, Jason Smith, 2002, "All rights reserved"), so it is not shown to be that release and must not be committed.
- **Spec:** [`documentation-system.md`](../../specs/documentation-system.md):
    - [§3.3](../../specs/documentation-system.md#33-the-docs-gate-run-by-autopilot-after-every-step-and-by-ci-on-every-pr) item 1 names the new hook-output check;
    - [§1](../../specs/documentation-system.md#1-site-structure): the size of `docs/assets` is now about 11 MB, not 3.3 MB.

`docs.yml` was not changed: its `docs-gate` job already runs the full `check.py`, so the new check runs there on every PR. The `pr-body` job and the freshness check of the figure SVGs were already in place.

## Why

Prompt: [next-phase.md · D6](../../playbooks/next-phase.md#d6-docs-pipeline-in-ci). Thomas asked for a minimal D6 for this tick. Two reasons for these three items:

- the repository is now public, so the font licence matters;
- a broken `hooks/progress.py` would leave the landing page and the Progress tab without their status, and `mkdocs build --strict` would not notice: an HTML comment is valid output.

No decision-log entry: the step decided no behaviour.

## How to test it

The step test, from the repository root:

```bash
python3 -m unittest tools/docs/test_check.py && python3 tools/docs/check.py --only build
```

To see the check fail on the real site, disable the hook in `mkdocs.yml` (comment out `- hooks/progress.py`) and run `python3 tools/docs/check.py --only build`. Restore the file afterwards.

### Deferred to a follow-up step

These parts of the [D6 prompt](../../playbooks/next-phase.md#d6-docs-pipeline-in-ci) are not done:

3. **`hooks/shared_images.py`**, the size hook from depictio. [§1](../../specs/documentation-system.md#1-site-structure) makes it due before the first mike version, or when `docs/assets` passes 50 MB. Neither has happened: no mike version exists, and `docs/assets` holds about 11 MB of tracked files.
4. **The same PNGs in CI:** the figure scripts still render PNGs locally only, because the font is not committed ([§3.3](../../specs/documentation-system.md#33-the-docs-gate-run-by-autopilot-after-every-step-and-by-ci-on-every-pr) item 3). CI checks SVGs only.
5. **The F4 and F6 figures:** the magic-link and share-link sketch, and the three telemetry systems.
6. **CI for `test_check.py`:** no workflow runs the new unit tests yet. This step did not edit workflows. The check itself runs in CI through `docs-gate`.

### For Thomas

1. **Commit the font or not** ([inbox #1](../../reviews/inbox.md#1-virgil-font-licence-blocks-publishing-the-hand-drawn-figures-font)). The OFL now allows committing the `excalidraw/virgil` font with `OFL.txt`, and that would let CI render the PNGs (deferred item 4). The font in use locally is a different build, not covered by that licence as far as the sources show. Committing would mean switching to `Virgil.woff2` and checking that the sketches still render the same.
2. **This page has no sketch.** A `done` Progress page must embed a sketch pair ([§3.4](../../specs/documentation-system.md#34-a-sketch-for-every-step)). Before it is marked done, it needs either a small sketch or an exemption.
