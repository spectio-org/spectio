## What changed

- **`.github/workflows/previews.yml`** ([spec §7.1](../../specs/dev-environment-and-testing.md#71-static-previews-on-cloudflare-pages-now)):
    - **Wave approval.** The workflow now also runs on `labeled`. A `wave-approved` label added by the repository owner on a PR into `main` deploys the PR head under `wave-w<n>`. The wave comes from the PR title, which must name exactly one `W<n>`. Every other label event skips the job.
    - **Manual runs** (`workflow_dispatch`) refuse the reserved aliases `main`, `production`, `pr-*`, `wave-*` and `v<digit>*`.
    - **The PR head is built,** not GitHub's merge commit, so the footer's `build <sha>` names exactly what is served.
    - **The verification step** now also waits until the branch alias shows the new SHA.
    - **The PR comment** gives the build SHA, and wave previews get their own comment. Only the bot's own comment is updated.
    - **Hardening:** `permissions: {}` at the top with per-job grants; actions pinned by commit SHA, at the same majors; `wrangler@4.153.0` pinned; every event value reaches the shell through `env:`.
- **`tools/previews/versions_page.py`:**
    - it pages with `result_info.total_pages`;
    - it leaves out deployments whose `latest_stage.status` is not `success`;
    - it prints the API's key names, never values, to the CI log.
- **Tests:** `tools/previews/test_versions_page.py` (7 tests) uses the live API shape; `tools/previews/test_alias.py` (5 tests) runs the workflow's own alias step.
- **`.devcontainer/devcontainer.json`:** Node 22 → 24, to match [§1](../../specs/dev-environment-and-testing.md#1-toolchain-pinned-in-devversionsenv).
- **Spec updates** in [`dev-environment-and-testing.md`](../../specs/dev-environment-and-testing.md):
    - §7.1: wave approval and its residual risk, the token scope and secret names, the `/versions` fields, whether direct uploads count as builds, and the 2026-10-27 checks;
    - §7.2: prebuilds, the static check, and what Thomas must check live.
- **Review record:** [`docs/reviews/code/D5.md`](../../reviews/code/D5.md). Figure: `tools/diagrams/d5_previews.py`.
- **GitHub:** the label `wave-approved` was created in the repository, which the new path needs.
