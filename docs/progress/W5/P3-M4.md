## What changed

### G1 · Paper chrome on the shared lite-board components

Three of the four shared components in `design/ui-canvas/` now draw the Paper shell of [ui-spec §7](../../specs/ui-spec.md#7-consistency-with-depictio-reuse-plan). Thirty lite boards import them, and none of the boards was edited: the components keep their props (`crumbs`, `active`, `title`, `sub`, `back`).

- **`LiteTopbar`** (floating top bar):
    - Breadcrumbs: the `crumbs` prop ("Runs / rnaseq-2026-10-25 / Tasks") becomes `Home › Runs › rnaseq-2026-10-25 › Tasks` in a `<nav aria-label="Breadcrumb"><ol>`. Every crumb but the last is a link to its board; the last has `aria-current="page"`. Below 1000 px, the crumbs between Runs and the last fold into "…", the last crumb ellipsizes, and the search box becomes an icon button. A crumb with no board is plain text.
    - Theme toggle: `<button role="switch" aria-checked="false" aria-label="Dark theme">`.
    - Search (⌘K), notifications and the account avatar, as Thomas answered [inbox #72](../../reviews/inbox.md#72-assumed-the-paper-shell-in-001-leaves-out-search-notifications-and-the-avatar) (b): native `<button disabled>` controls named "Search (not in 0.0.1)", "Notifications (not in 0.0.1)" and "Account (not in 0.0.1)". They are dimmed and never take focus. The search box also shows "Search (not in 0.0.1)" as text.
    - The "SLURM · server on login1" chip moved to the sidebar foot.
- **`LiteSidebar`** (foldable sidebar):
    - A "WORKSPACE" eyebrow and a fold button, `<button aria-expanded aria-controls="lite-nav-items">`.
    - A new prop, `collapsed`, draws the folded 92 px icon rail, with the server status as "✓ on". The labels stay readable by a screen reader.
    - The foot shows the server status: "Spectio 0.0.1 · online", then "SLURM · server on login1 · your account amartin".
    - The Runs count reads "Runs, 6 active runs" through visually hidden text.
- **`MLiteTopbar`** (phone): the same controls in the 48 px row: the server chip, the disabled search, notifications and account buttons, and the theme switch (44 px). Below 390 px the search and notifications placeholders are hidden, so the row fits at 320 px.
- **`MLiteTabbar`**: unchanged. It already was the floating bottom tab bar of Paper.

### G2 · The launch boards: engine buttons and path-or-Git

**What changed.** `LiteLaunch`, `LiteLaunchSnakemake` and `MLiteLaunch` in `design/ui-canvas/` now draw the launch form of [ui-spec §4.6](../../specs/ui-spec.md#46-launch-and-relaunch) (note 2026-10-29) and [P1](../../plans/P1-walking-skeleton.md) Assumption 2:

- **Page head** (desktop), as in [ui-spec §7](../../specs/ui-spec.md#7-consistency-with-depictio-reuse-plan): a 48 px icon tile with the sidebar's Launch tint, "Launch a workflow" in the Outfit heading font, one line of description, and Launch on the right. A second Launch ends the aside, which stays in view from 1200 px; both share one state, and when disabled both show the reason ("Fill the required field: samples").
- **Pipeline:** one field takes an absolute path, a GitHub or nf-core name, or an `https://` or `ssh` URL. Beside it are **Revision (Git only)** and Load. For a path, Revision is disabled and says why. `LiteLaunchSnakemake` shows a Git repository at a revision: Revision is required, and a short name is read as GitHub before Load ("Read as GitHub: https://github.com/…").
- **Engine:** two native `<button aria-pressed>`, Nextflow and Snakemake, in a group labelled "Engine". The guessed one is pressed and shows a check mark. "Guessed from main.nf · change it if the guess is wrong" sits beside them; on a prefilled launch it reads "Nextflow, as in rnaseq-2026-10-25".
- **States**, drawn as cards at the foot of each board:
    - no guess, both files found (`LiteLaunch`, `MLiteLaunch`): no button is pressed and Launch waits for a choice;
    - no guess, neither file found (`LiteLaunchSnakemake`): Launch stays disabled with "No main.nf or Snakefile in this directory: check the path", whatever is pressed;
    - guess overruled (`LiteLaunch`): Snakemake pressed on a directory with no Snakefile, so Launch says it will refuse;
    - Git (`LiteLaunchSnakemake`): before Load with no revision, fetching, and not fetched (revision not found, with the other fetch failures listed);
    - refused input, following [api §5](../../specs/api-and-data-model.md#imports-are-untrusted-input): a `file://` URL (`LiteLaunch`, `MLiteLaunch`) and a revision that starts with `-` (`LiteLaunchSnakemake`).
