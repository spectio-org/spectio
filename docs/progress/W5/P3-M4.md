## What changed

### G1 · Paper chrome on the shared lite-board components

Three of the four shared components in `design/ui-canvas/` now draw the Paper shell of [ui-spec §7](../../specs/ui-spec.md#7-consistency-with-depictio-reuse-plan). Thirty lite boards import them, and none of the boards was edited: the components keep their props (`crumbs`, `active`, `title`, `sub`, `back`).

- **`LiteTopbar`** (floating top bar):
    - Breadcrumbs: the `crumbs` prop ("Runs / rnaseq-2026-10-25 / Tasks") becomes `Home › Runs › rnaseq-2026-10-25 › Tasks` in a `<nav aria-label="Breadcrumb"><ol>`. Every crumb but the last is a link to its board; the last has `aria-current="page"`. Below 1000 px, the crumbs between Runs and the last fold into "…", the last crumb ellipsizes, and the search box becomes an icon button. A crumb with no board is plain text.
    - Theme toggle: `<button role="switch" aria-checked="false" aria-label="Dark theme">`.
    - Search (⌘K), notifications and the account avatar, as Thomas answered [inbox #72](../../reviews/inbox.md#72-assumed-the-paper-shell-in-001-leaves-out-search-notifications-and-the-avatar) (b): native `<button disabled>` controls named "Search (not in 0.0.1)", "Notifications (not in 0.0.1)" and "Account (not in 0.0.1)". They are dimmed and never take focus. The search box also shows "Search (not in 0.0.1)" as text.
    - The "SLURM · server on login1" chip moved to the sidebar foot.
- **`LiteSidebar`** (foldable sidebar):
    - A "WORKSPACE" eyebrow and a fold button, `<button aria-expanded aria-controls="lite-nav-items">`.
    - A new prop, `collapsed`, draws the folded 92 px icon rail, with the server status as "✓ on". The labels stay readable by a screen reader.
    - The foot shows the server status: "Spectio 0.0.1 · online", then "SLURM · server on login1 · your account amartin".
    - The Runs count reads "Runs, 6 active runs" through visually hidden text.
- **`MLiteTopbar`** (phone): the same controls in the 48 px row: the server chip, the disabled search, notifications and account buttons, and the theme switch (44 px). Below 390 px the search and notifications placeholders are hidden, so the row fits at 320 px.
- **`MLiteTabbar`**: unchanged. It already was the floating bottom tab bar of Paper.

### G3a · Paper page bodies of the run boards

The run boards and their phone twins now open with the page head of [ui-spec §7](../../specs/ui-spec.md#7-consistency-with-depictio-reuse-plan): a tinted 48 px icon tile, the Outfit h1, a one-line description and the primary action on the right. `LiteHome` and `LiteRuns` already had it and are unchanged.

- **Run heads** (`LiteRunDetail`, `LiteRunDetailSnakemake`, `LiteRunObserved`, and the page behind `LiteCancelDialog`):
    - the pipeline logo sits in a 48 px tile with the Runs tint (`--sp-violet-50`), in place of a white bordered 52 px tile;
    - the run name wraps instead of overflowing, and the state line wraps as one sentence;
    - Cancel run and Copy form one group on the right. The page behind the cancel dialog shows Copy too.
- **States boards** (`LiteStates`, `LiteStatesRun`): a tile in the Runs tint and a one-line description. The rest of the old description is a caption under the panels. The run-detail loading skeleton draws the tile too.
- **Phone, top-level pages:**
    - `MLiteRuns` keeps its title and "live, updated" line in the compact top bar, as ui-spec §4.11 asks; it is unchanged.
    - `MLiteHome` already had its h1 in the body. It gains a tile in `--sp-indigo-100`, the `-100` step because the phone page is grey.
    - Its description now reads "4 running, 1 queued, 1 cancelling · live, updated 4 s ago", shortened from "4 runs running, 1 queued and 1 cancelling" to fit beside the tile.
- **Phone, run pages** (`MLiteRunDetail`, `MLiteRunObserved`, `MLiteCancelSheet`):
    - the back link, h1 and state line stay in the top bar;
    - the white run card starts with the pipeline in a 48 px tile (`--sp-violet-50`);
    - the card behind the cancel sheet shows Copy too.
- **Two G1 minors:**
    - UX-G1-12, `LiteTopbar`: below 1000 px, only the crumbs before the run fold. The link back to the run stays: "Home › … › rnaseq-2026-10-25 › Tasks".
    - UX-G1-13, `MLiteTopbar`: the search and notifications placeholders are 44 px wide, and the row gap is 2 px.
- **`crumbs` props** (UX-G1-11): no G3a board names an in-page tab in its crumbs. `LiteTaskFilesStates` does ("… / Tasks"); it is a G3b board.
