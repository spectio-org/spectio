Inspect fetches and reads it but never runs it, and every file it reads must stay inside the pipeline directory.

### Task 17 · Launch API

Branch `autopilot/P3-t17`, base `643dd89`, head `3cbf735` before the figure and this page; 7 commits, 25 files, +2480 −112 (+2132 −112 in `packages/`, +308 in `uv.lock`). The endpoints are owned by the [api §5 note of 2026-10-30](../../specs/api-and-data-model.md#5-endpoint-catalogue-api-v1) and [Imports are untrusted input](../../specs/api-and-data-model.md#imports-are-untrusted-input); the browser checks by [dev-env §15.3](../../specs/dev-environment-and-testing.md#153-001-on-a-cluster-architecture-and-safety-without-accounts) req. 4 and 7; the rules assumed for the local-only order by [inbox #86](../../reviews/inbox.md#86-assumed-the-001-launch-api-served-in-local-mode-only-before-sign-in). This list names the files.

- **The API** (`packages/spectio-server/src/spectio_server/api/`; new dependencies `jsonschema>=4.23,<5` and `pyyaml>=6.0.2,<7`):
    - `workflows.py` (444 lines): `GET /api/v1/workflows:inspect?location=&revision=`.
        - `resolve` checks the location: an absolute path to a directory this account can read, or Git (`owner/repo`, `https://` or `ssh://`), under `git_url` and `check_revision`.
        - `fetch` clones a Git location once per revision into `<data dir>/pipelines/<host>/<path…>/<revision>/`, under a temporary name then renamed. `git` runs as an argument list with `-c protocol.allow=never` and only `https` and `ssh` turned back on, no terminal, `GIT_TERMINAL_PROMPT=0`, and a 300 s timeout that kills its process group.
        - `inspect_dir` reads the directory and never runs it: `entry_files`, the engine guess, the Nextflow manifest name and version, the profiles, and the schema with its source. Every file is opened one path part at a time from a descriptor of the pipeline directory, with `O_NOFOLLOW` (`_open`, `_regular`, `_read`), and only a regular file of at most 1 MiB is read. YAML aliases are refused. `nextflow.config` is scanned in linear time and never run.
        - `engine_versions`: both engines' versions from `check_engine`, on each inspect.
    - `runs_write.py` (207 lines): `POST /api/v1/runs`. It checks the whole body before writing anything: the location as inspect does, the chosen engine's entry file, the profiles, the name, and the params against the pipeline's schema (`jsonschema`, draft 7 or 2020-12, an empty `referencing.Registry`, so no `$ref` is retrieved). Then the run directory and its manifest, then the rows and the `launch` command in one transaction. `201` with a `Location` header.
    - `browser.py` (66 lines): one middleware before every route. Host allow-list (`400`), cross-site refusal (`403`), and on writes `Origin` (`403`) and a JSON body (`415`).
    - `problems.py` (57 lines): `422 validation-failed` with `errors: [{field, message}]`, `field` a dotted path; pydantic's echoed `input` is dropped.
- **The server:**
    - `app.py`: `create_app(settings, writer)` mounts the two routers only when `no_api_reason(settings)` is `None`: kind `local`, and `shared_host()` finds no sign of a cluster node or a shared machine. Otherwise every `/api/v1` path answers `404` with the reason. The decision is taken once and kept on `app.state.no_api`.
    - `serve.py`: `Started.no_api` carries that decision, and `start_text(settings, node, user, no_api)` prints it.
    - `store/runs.py` (123 lines): `insert_run` and `first`, shared by `POST /runs` and the rebuild (one engine per location, api §7).
    - `rebuild.py`: uses `insert_run`, and refuses a Git location that fails the import rule (SEC-P3T11-01 (r3)).
    - `sink.py`: `active_launches` keeps a launch until its head is reported ended, also after its run ended (CR-P3T09-R5-03).
- **Tests:** `tests/api/test_launch.py` (30 tests, 58 cases), `tests/api/test_req4_req7_browser.py` (7 tests), `tests/security/test_shared_host.py` (6 tests), 4 new tests in `tests/test_serve.py`, and four schema fixtures in `tests/data/`. Dev dependencies `httpx>=0.27`, `types-jsonschema`, `types-pyyaml`.
- **Specs** (P1 Process: the owning spec changes in the same PR):
    - [api §5](../../specs/api-and-data-model.md#5-endpoint-catalogue-api-v1): the dated note of 2026-10-30 (the worker's commit). The docs commit adds two bullets: a symlinked file counts as absent, and where the API is not served (CR-P3T17-06 (r4)).
