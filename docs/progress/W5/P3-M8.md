- **The files package** (`packages/spectio-server/src/spectio_server/files/`, new):
    - `confine.py` (228 lines): the walk of [checking-scenarios §11.1](../../specs/checking-scenarios.md#111-how-files-reach-a-check). `open_confined` and `list_confined` open each folder with `O_DIRECTORY|O_NOFOLLOW` from the root's descriptor and check its owner, then the file with `O_NOFOLLOW|O_NONBLOCK`: a regular file of the user. `safe_rel` refuses an absolute name, `.` or `..`, a control character, a component over 255 bytes or a name over 4096 (`0fee201`). Also `stat_confined`, `tail`, `read_at`, `size_of`.
    - `pool.py` (72 lines): `FilePool`, its own daemon threads with a bounded backlog; a caller waits at most its timeout, then gets `Stalled`; a full pool refuses at once.
    - `redact.py` (319 lines): `redact_command_run`, a shell lexer that hides the value of every assignment word (at a command's start, after `export` and the other declaring words, after `-e` or `--env`, inside here-documents, arrays), failing closed from the first line it cannot read or past 64 nested constructs (`297ba97`, `0fee201`). `strip_escapes` removes CSI, OSC and C0/C1 controls.
    - `taskfiles.py` (371 lines): the eight Nextflow names served, the five listing states, `check_name` (a Snakemake name equals a recorded path byte for byte), `read_task_file` (no link followed for a job file, `f362fc5`; a NUL in the first 8 KiB is binary), and `task_work_rel`, `launch_rel` and `native_id`, the checks the projector applies to a path or ID from an event.
- **Routes** (`api/taskfiles.py`, 187 lines): `GET /tasks/{id}/attempts/{n}/files` and `…/files/{name}` (`?tail=`, `?download=`, one `Range`), run in the routes' pool with 5 s; refusals map to `422 file-not-allowed`, `404 log-not-found`, `410 log-cleaned`, `415 binary-file` and `503 runner-offline`; other `OSError`s to 503 (`EIO`, `ESTALE`) or 404, with a fixed text (`0fee201`). `api/logs.py` reads the run logs through the same walk and pool, `.spectio/nextflow.log` first, with escape sequences removed.
- **Store and projector:** migration `0006_attempt_files.py` adds `attempts.work_dir`, `native_id` and `logs`. Nextflow's `_where` keeps the work directory only when it is `<2 hex>/<30 hex>` below the run's; Snakemake's `_logs` keeps a path only inside the launch directory, from `job_info`, `job_error` and the new `snakemake.slurm_submitted`. Others are counted `path_outside_run` or `bad_native_id` in the spool cursor's drops.
- **SDK** (`spectio_sdk/events.py`): `SnakemakeSlurmSubmitted` (`jobid`, `external_jobid`, `log`) and `SnakemakeJobError.aux.external_jobid`. The logger plugin does not send them yet (P1 Task 7).
