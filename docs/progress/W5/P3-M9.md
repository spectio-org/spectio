- **Snakemake logger plugin** (`__init__.py`, +37 −5): three patterns pinned to Snakemake 9.27.1, each matching the whole message and citing its source line:

    - "Write-protecting output file <path>." (`dag.py:932-936`) gives `snakemake.protected`;

    - Only an untyped record is read as a text; its `snakemake.log` (level only) comes first and the text itself is never sent. The dry run's "Would remove…" and any reworded text stay `snakemake.log`.
    - Each `temp_removed` path goes once per launch: Snakemake 9.27.1 logs every `make_reads` removal of the synthetic pipeline twice (T2 row 19). The plugin remembers at most 65536 paths.
- **`nf-spectio`** (`SpectioPlugin.groovy`, +20 −2): `onFlowCreate` sends `cleanup` (as Nextflow reads it, `!config.cleanup` by Groovy truth) and `clusterOptionsSet`, from a walk of the `process` config and its selectors, depth at most 8; the flag only, never the text.
