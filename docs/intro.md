This logger connects Snakemake to [Spectio](https://github.com/spectio-org/spectio), an open-source run manager for HPC and Kubernetes that launches, monitors and relaunches Nextflow and Snakemake runs on your own cluster.

Version `0.0.1` writes each run's events to Spectio's spool, which Spectio reads to show the run, its rules and its jobs. It is added to Snakemake's own output, never in its place, and it never fails a run. Install it where Snakemake runs and name it with `--logger spectio`. A run started from a terminal writes its spool in `.spectio/events/` of the directory Snakemake starts in and, when `~/.spectio/` exists, a pointer that lets a Spectio server of the same user find the run. The plugin has no settings. Spectio's documentation is at <https://spectio.pages.dev>.
