# Features

What 0.0.1 does, and what comes later. Pages for features that are not built yet say so at the top.

<div class="grid cards" markdown>

-   :material-play-network:{ .lg .sp-c-violet } **[Runs](runs.md)**

    ---

    Launch from a form, follow every run, resume a failed one, copy it to a new launch.

-   :material-server-network:{ .lg .sp-c-sky } **[Runners](runners.md)**

    ---

    SLURM through a login node, or one machine. Kubernetes comes later.

-   :material-api:{ .lg .sp-c-indigo } **[API and CLI](../api/index.md)**

    ---

    A REST API under `/api/v1` with live events, and five commands.

-   :material-gate:{ .lg .sp-c-amber } **[QC gates](gates.md)** *(later)*

    ---

    Optional stops between stages for a check.

-   :material-shield-account:{ .lg .sp-c-coral } **[Administration](administration.md)** *(later)*

    ---

    Users and groups, sign-in, plugins, backups.

-   :material-chart-box:{ .lg .sp-c-green } **[Depictio](depictio.md)** *(later)*

    ---

    Finished runs become dashboards.

-   :material-flask-outline:{ .lg .sp-c-sky } **[LabID](labid.md)** *(later)*

    ---

    Launch from LabID samples, and send the results back with their provenance.

-   :material-robot-outline:{ .lg .sp-c-violet } **[AI agents](ai-agents.md)** *(later)*

    ---

    Optional: agents suggest at QC gates, with their own access and a full record.

-   :material-compare-horizontal:{ .lg .sp-c-sky } **[Spectio and other tools](other-tools.md)**

    ---

    A neutral comparison with Seqera Platform, panoptes, FlowO, Galaxy, Flyte and others.

</div>
