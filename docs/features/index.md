# Features

What 0.0.1 does, and what comes later. Pages for features that are not built yet say so at the top.

<div class="grid cards" markdown>

    ---

-   :material-server-network:{ .lg .sp-c-sky } **[Runners](runners.md)**

-   :material-api:{ .lg .sp-c-indigo } **[API and CLI](../api/index.md)**

-   :material-shield-account:{ .lg .sp-c-coral } **[Administration](administration.md)** *(later)*

    ---

    Users and groups, sign-in, plugins, backups.

-   :material-chart-box:{ .lg .sp-c-green } **[depictio](depictio.md)** *(later)*

    ---

    Finished runs become dashboards.

-   :material-compare-horizontal:{ .lg .sp-c-sky } **[Spectio and other tools](other-tools.md)**

    ---

    A neutral comparison with Seqera Platform, panoptes, FlowO, Galaxy, Flyte and others.
