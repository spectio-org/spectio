# depictio

!!! note "Later: not in 0.0.1"
    The hand-off to depictio is planned and not built. The version is not set. See the [roadmap](../roadmap/index.md).

Spectio and [depictio](https://github.com/depictio/depictio) are meant to form one platform:

- **The same accounts and groups,** once Spectio has accounts.
- **Results become dashboards.** When a run finishes, its outputs are handed to depictio, which builds the dashboard from them.
- **The same look.** Spectio's interface follows depictio's patterns and branding model.
- **Installed together or apart,** on one server or cluster, or separately.

Spectio is its own project: 0.0.1 does not need depictio and does not talk to it.
