Spectio and [Depictio](https://github.com/depictio/depictio) form one platform:

- **The same accounts and groups.** You sign in once; Depictio accounts work in Spectio.
- **Results become dashboards.** When a run finishes, its outputs are handed to Depictio, which builds the dashboard from them.
- **The same look.** Spectio uses Depictio's branding model, and its interface follows the same patterns.
- **Installed together or apart.** Depictio and Spectio can run side by side on one server or cluster, or separately.

Design details: [Depictio ecosystem reuse](../specs/depictio-ecosystem-reuse.md), [API and data model §13](../specs/api-and-data-model.md).
