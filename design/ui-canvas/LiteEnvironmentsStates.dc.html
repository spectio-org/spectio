Environments: states

Loading, the file states, a missing environment, Make default, the delete dialog and the form's 412 and 409 (ui-spec §4.8.1, api §5.4). Cards are drawn without their summary: the full card is on LiteEnvironments.

A · LOADING THE LIST

Loading environments…

The cards' skeleton; New environment is shown at once. At Launch the Environment row reads the same words with the row's skeleton.

B · THE LIST COULD NOT BE READ

Environments could not be read. The server did not answer; your environments are unchanged.

A network or server error on GET /environments. At Launch the row says the same with Retry, and Launch still works: "The server's default environment will be used".

C · FILE REFUSED

Spectio does not read ~/.spectio/environments.toml: other users can write to it. Fix it with chmod 600 ~/.spectio/environments.toml; Spectio will not change it.

The reason is the server's detail (owner, mode, not a regular file, a link): it names the check, never a byte of the file. Only the built-ins are listed; launches with them still work.

D · FILE INVALID

~/.spectio/environments.toml has a mistake: Expected (at line 7, column 13). Only the built-in environments are listed until it is fixed.

Waits until the mistake in the file is fixed

SLURM (from spectio init)

SLURMBuilt-inDefault
The detail is the parser's message cut at its first quote or "(", then its place, at most 200 characters (api §5.4): never a token, a name or a value of the file. Nothing of spectio.toml is printed in this state either.

E · FILE UNREACHABLE

Spectio cannot read the cluster's files right now. Only the built-in environments are listed.

Waits until the cluster's files can be read
The file system did not answer in time, or an I/O error (ESTALE, EIO). A launch naming one of your environments waits too (503); the built-ins still launch.
