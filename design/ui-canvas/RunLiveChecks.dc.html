How these values get here

  1. Nextflow reports each finished task and each published file (plugin nf-spectio: paths only, no content).
  2. Spectio matches the path against the stage's watched globs.
  3. The runner on hpc-login-1 reads that one file (≤ 5 MB) and parses it with the MultiQC module the final report will use.
  4. Only the values come back; the files stay on the cluster.
At the end of stage 4, MultiQC's general stats are read once (when: stage_done). A later gate reuses these values when the file has not changed.
