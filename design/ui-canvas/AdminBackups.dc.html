CLI equivalent every action on this page, from a terminal or a CronJob 
# create, list and check
spectio backup create --include db,files,keys --destination seaweedfs
spectio backup list
spectio backup validate spectio-backup-demo-20261025T020000Z
# restore: dry run first, always
spectio backup restore spectio-backup-demo-20261025T020000Z --dry-run
# schedule and retention (stored as a UI override)
spectio backup schedule set --daily 02:00 --retention smart
# move one project to another instance (depictio-compatible)
spectio migrate project liver-time-course --to-server demo-prod --dry-run
