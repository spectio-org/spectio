# rnaseq-demo-lab v3 (draft)
stages:
  - id: align
    match: ["*:ALIGN_STAR:*"]
    important: true
    watch:
      - id: star_log
        files: "star_rsem/log/{sample}.Log.final.out"
        when: task_done
        max_size: 5MB
        checks:
          - id: unique
            from: "multiqc:star.uniquely_mapped_percent"
            min: 70
            severity: warn
          - id: multi
            from: "multiqc:star.multimapped_percent"
            max: 8
            severity: warn
        on_fail: flag
  - id: quantify
    match: ["*:QUANTIFY_*:*"]
    watch: [ … ]
Who reads the file The runner of the run's environment, on the cluster, as the run's owner. The engine only says which file was written. The value is parsed by MultiQC's STAR module, so it matches the final report. Runs started from a terminal get these checks too, if a runner can read their directory.
