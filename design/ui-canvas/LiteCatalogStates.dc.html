Catalog: states

Loading, a list error, the file states, a missing entry, the delete dialog and the form's 412 and 409 (ui-spec §4.7.1, api §5.6). The same words and waiting actions as the Environments list (LiteEnvironmentsStates), except that the catalog has no built-ins: in every file state but ok the list is empty.

A · LOADING THE LIST

Loading the catalog…

The rows' skeleton, at a row's height; Add pipeline is shown at once. At Launch the picker's skeleton keeps the picker's height (LiteLaunch), and Save to catalog waits: "Waits until the catalog is read".

B · THE LIST COULD NOT BE READ

The catalog could not be read. The server did not answer; your catalog is unchanged.

A network or server error on GET /catalog. At Launch the picker says the same with Retry, and the free Pipeline field and Try a test pipeline still work.

C · FILE REFUSED

Spectio does not read ~/.spectio/catalog.toml: other users can write to it, and an entry names code that Launch loads. Fix it with chmod 600 ~/.spectio/catalog.toml; Spectio will not change it.

Waits until the catalog file can be read
The reason is the server's detail (owner, mode, not a regular file, a link): it names the check, never a byte of the file. No row is listed.

D · FILE INVALID

~/.spectio/catalog.toml has a mistake: a value breaks its rule (at line 7, column 12). No pipeline is listed until it is fixed.

Waits until the mistake in the file is fixed
An unknown key, a wrong type or a value outside its rule (a refused location or revision too) makes the whole file invalid; the detail is the message cut at its first quote or "(", then its place, at most 200 characters: never a name or a value of the file (api §5.6, as §5.4). At Launch: "Your catalog file has a mistake: see Manage catalog".

E · FILE UNREACHABLE

Spectio cannot read the cluster's files right now. Your catalog is not listed until they answer.

Waits until the cluster's files can be read
The file system did not answer in time, or an I/O error (ESTALE, EIO). At Launch: "Your catalog cannot be read right now"; a typed pipeline still loads.
