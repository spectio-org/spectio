Legend

The words, colours and icons of the 0.0.1 screens. Every state shows an icon and a word, never colour alone.

Run states

Queued Saved; Spectio is starting the engine in its tmux session on the login node.
Running The engine is alive and sending events. Tasks run on SLURM.
Succeeded The engine reported success and its head exited.
Failed A task failed for good, the engine stopped, or the head was lost. The run shows the failure class and the message.
Cancelling Cancel was asked; Spectio is stopping the engine, which stops its SLURM jobs.
Cancelled The engine and its tasks have stopped.
Six states in 0.0.1 (ui-spec §3.1). Rail colours are the run-state tokens of spectio-tokens.css.

Task states

Not scheduled Planned by the engine, never started.
Pending Waiting in the engine.
Submitted Handed to SLURM, waiting for a node.
Running Running on a node.
Succeeded Finished with exit 0.
Cached Taken from an earlier run (Nextflow -resume).
Failed Its last attempt failed.
Aborted Stopped by the engine or by Cancel; not a failure.
Retried Not a state: a task whose last attempt is not its first.
Task and attempt states are owned by api-and-data-model §7.2; the Snakemake mapping is [to be validated] there.
