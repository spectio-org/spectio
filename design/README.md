# Design sources

- **`tokens/spectio-tokens.css`.** Design tokens v0.2 as CSS custom properties:
  - surfaces, lines and text;
  - accent;
  - the 8 run states;
  - section colours (Workflows = coral 700 `#A54666`, distinct from depictio's Dashboards orange);
  - actors and data-viz colours;
  - the Sky scale;
  - dark mode.
- **`ui-canvas/`.** Snapshot of the UI canvas: one `.dc.html` file per board, and `canvas.json` for the board positions and pages (structure, screens, shared shell, mobile).
  - The boards use a small template syntax: `sc-for`, `sc-if` and `dc-import` for shared components such as `AppSidebar`, `AppTopbar`, `AdminNav` and `MobileTabbar`.
  - [`tools/canvas/render.js`](../tools/canvas/render.js) renders any board to PNG without the canvas host.
- **`brand-canvas/`.** Logo and colour explorations from before the name Spectio was chosen. Some file names keep the earlier working names. `SpectioUIColors` is the current UI palette board.

## 0.0.1 lite boards

The page **0.0.1 lite** of `ui-canvas/canvas.json` holds the screens of the 0.0.1 walking skeleton ([`mvp-0.0.1.md`](../docs/specs/mvp-0.0.1.md), [dev-env §15.1](../docs/specs/dev-environment-and-testing.md#151-capabilities-by-version)). They are cut down from the full boards of 2026-10-26, which stay unchanged as the reference for later versions. They keep the look: the tokens, the run-state colours with an icon and a word, and the shell. The app bar starts with the complete Spectio logo, the emblem and the "Spectio" wordmark, on desktop and on the phone; the emblem alone is the favicon, in the browser tab (Thomas, 2026-10-28; [ui-spec §2 note](../docs/specs/ui-spec.md#2-main-navigation)). The Nextflow, Snakemake and nf-core logos mark the pipeline on the run, launch and home boards (files in `docs/assets/logos/`, which `tools/canvas/render.js` also reads). Each section of the run detail and launch boards is a collapsible `<details class="cx">` with a light line icon, a summary shown when closed and a chevron. Desktop boards render at 1440 × 1180, phone boards at 390 × 844.
