# spectio-open

Spectio Open, the open edition of Spectio, launches, monitors and steers Nextflow and Snakemake runs: one place to follow a run, see why a job failed, resume it, and gate it on quality checks.

This `0.0.0` release only holds the name on PyPI while the first real version is built. It installs a `spectio-open` command that prints this notice and its version.

Source, design documents and progress: <https://github.com/spectio-org/spectio>.
